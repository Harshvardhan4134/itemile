## 🏢 About Lendlly

Lendlly is a peer-to-peer rental marketplace that connects people who want to rent items with those who have items to share. Our platform enables users to rent, share, and discover items in their community - from electronics and tools to sports equipment and more.

### Mission
To build a sustainable sharing economy that helps people save money, reduce waste, and build stronger communities through shared resources.

### Vision
To become the leading platform for peer-to-peer rentals and swaps, creating a world where access is more valuable than ownership.

## 🚀 Getting Started

### For Developers

#### Prerequisites
- Node.js 18+ and npm
- Firebase account
- Google Cloud Console account (for Maps API)

#### Installation

```bash
# Clone the repository
git clone https://github.com/Harshvardhan4134/Rent-share.git

# Navigate to project directory
cd Rent-share

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Edit .env with your Firebase credentials

# Start development server
npm run dev
```

#### Environment Variables Required

```env
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
VITE_GOOGLE_MAPS_API_KEY=your_google_maps_key
VITE_CLOUDINARY_CLOUD_NAME=your_cloudinary_name
VITE_CLOUDINARY_UPLOAD_PRESET=your_upload_preset
```

### For Users

1. **Sign Up:** Create an account with email or Google
2. **Complete Profile:** Add your name, phone, and location
3. **KYC Verification:** Submit verification documents for full access
4. **Start Exploring:** Browse items or post your own
5. **Rent or List:** Start renting items or earning from yours
